# Todo App (MERN)\n\nA modern blue‑themed Todo application built with the MERN stack.\n\n## Features\n- Create, read, update (toggle complete) and delete todos\n- Responsive UI built with React + Vite\n- Axios for API calls with loading & error states\n- Express server with CORS and robust error handling\n- MongoDB persistence via Mongoose\n\n## Project Structure\n
root/\n├─ backend/            # Express API\n│   ├─ server.js\n│   ├─ package.json\n│   └─ .env.example\n├─ frontend/           # React Vite app\n│   ├─ src/\n│   │   ├─ App.jsx\n│   │   ├─ App.css\n│   │   └─ main.jsx\n│   ├─ index.html\n│   └─ package.json\n└─ README.md\n\n\n## Prerequisites\n- Node.js (v20 or later)\n- npm or yarn\n- MongoDB running locally or a remote connection string\n\n## Setup Instructions\n\n### 1. Clone the repository\nbash\ngit clone <repo-url>\ncd <repo-folder>\n\n\n### 2. Backend\nbash\ncd backend\ncp .env.example .env   # edit if needed\nnpm install               # or yarn\nnpm run dev               # starts server on PORT (default 5000)\n\nThe API will be available at `http://localhost:5000/api/todos`.\n\n### 3. Frontend\nbash\ncd ../frontend\ncp .env.example .env   # optional – VITE_API_URL\nnpm install               # or yarn\nnpm run dev               # Vite dev server (default http://localhost:5173)\n\nIf your backend runs on a different host/port, set `VITE_API_URL` in a `.env` file inside `frontend`:\nenv\nVITE_API_URL=http://your-backend-host:port\n\n\n### 4. Build for Production\nbash\n# Backend\ncd backend\nnpm install && npm run start\n\n# Frontend\ncd ../frontend\nnpm run build   # creates ./dist\n\nServe the `frontend/dist` folder with any static server (e.g., Nginx, Netlify) and ensure the backend API URL is correctly set.\n\n## API Endpoints\n| Method | Endpoint | Description |\n|--------|----------|-------------|\n| GET    | `/api/todos` | Get all todos |\n| POST   | `/api/todos` | Create a todo (JSON: `{ "text": "..." }`) |\n| PATCH  | `/api/todos/:id` | Update fields (e.g., `{ "completed": true }`) |\n| DELETE | `/api/todos/:id` | Delete a todo |\n\n## License\nMIT\n
